# 🏥 Prescripto — Smart Healthcare & Doctor Appointment Booking Platform

### A Final-Year B.Tech Computer Science & Engineering Project

Prescripto is a full-stack healthcare web application developed as my final-year B.Tech CSE project. The platform aims to simplify doctor discovery, appointment booking, and online consultations by bringing essential healthcare services together in one user-friendly application.

Built using the MERN stack, Prescripto integrates an AI-powered chatbot, video consultation functionality using ZegoCloud, and Razorpay payment integration in test mode.

## ✨ Key Features

- 👨‍⚕️ **Doctor Discovery:** Explore doctors and their specializations.
- 📅 **Appointment Booking:** Schedule and manage doctor appointments.
- 🤖 **AI-Powered Chatbot:** Provide conversational assistance to users.
- 📹 **Video Consultations:** Support remote consultations using ZegoCloud.
- 💳 **Payment Integration:** Razorpay test-mode payment workflow.
- 🔗 **Stripe Integration:** Stripe-related code is included but currently commented out.
- 📱 **Responsive UI:** User-friendly interface across different screen sizes.
- 🗄️ **Database Management:** MongoDB integration for application data.
- ⚙️ **REST APIs:** Backend services built using Node.js and Express.js.

## 🎯 Project Objective

The primary objective of Prescripto is to make healthcare services more accessible and convenient through digital technology. It brings doctor discovery, appointment scheduling, AI-assisted interactions, and online consultations into a single platform.

This project demonstrates the practical application of full-stack web development, database management, third-party API integration, and modern software engineering concepts.

## 🛠️ Tech Stack

**Frontend:** React.js, JavaScript, HTML5, CSS3

**Backend:** Node.js, Express.js, REST APIs

**Database:** MongoDB

**Integrations:** ZegoCloud, AI-powered chatbot, Razorpay (test mode)

**Tools:** Git, GitHub, and project-configured development and deployment tools

## ⚙️ How It Works

1. Users explore doctors and their specializations.
2. Patients schedule and manage appointments.
3. Users can access chatbot assistance.
4. Video consultations are supported through ZegoCloud.
5. Razorpay test mode supports payment workflow testing.

## ⚠️ Disclaimer

Prescripto is an academic software project. The chatbot is intended for assistance and does not replace professional medical advice. Razorpay is configured for test-mode use, and Stripe integration code is currently commented out.
